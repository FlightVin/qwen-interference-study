# qwen-interference-study

Preliminary study: does easier practice on a specified mathematical skill improve GRPO learning
on harder problems that use that skill? Model: Qwen/Qwen3-1.7B, non-thinking mode, full-parameter
GRPO, one job per GPU on CMU Babel.

- Canonical instruction: [`project.md`](project.md).
- Research records: [`research/`](research/) (STATE, CHECKLIST, PROTOCOL, DECISIONS, REVIEWS, READING).
- Execution harness: `slurm-agentic-engineering/` (separate repo, excluded from this one).
