# Research narrative — November 2026 (study s02)

## 2026-11-15 23:10 – 23:28 EST
Mandate received. Design choice: procedural arithmetic tasks with exact answers and short responses, so that rounds
are fast and success is tunable. Target family: base-9 addition, where a known failure is applying decimal carries.
This gives natural candidates: decimal addition of the same strings (a competing procedure), base-7 addition (shared
non-decimal carry), and terse multiplication (a competing behavioural demand: no working). Main reference: the same
target prompts trained alone, with the same raw gradient weight. The theory in main.pdf predicts that harm persists
mainly where target success is near zero (few mixed groups); stratifying the target pool by digit count gives several
initial success levels inside one run pair.

## 2026-11-16 00:25–00:40 EST — calibration 2 and grader audit
Calibration 2 (job 11167621, commit 627ad13; 64 sel problems x 16 samples, cap 4,096, temperature 1) gave base pass@1:
countdown n3/n4/n5 85.3/52.0/24.2%; caesar s4/s8/s12 27.0/8.2/4.5%; MBPP 38.4%; ARC 68.8%. Countdown answers are long
(mean 634/1,777/2,230 tokens) and n4/n5 truncate at 17-19%: truncation is a confound for countdown. Caesar, MBPP and ARC
answers are short (290-590 tokens, truncation <= 0.2%).
The audit of wrong answers found three grader artefacts, all of which mark correct answers wrong:
(1) MBPP: only the last code block was run; models often end with a usage block holding only an assert.
(2) countdown: models box the expression and then box its value; the last box ("29") was graded.
(3) ARC: 170 of 1,024 answers (17%) give "Final Answer: (D)" without a box.
Fixes (commit 602b151): run all defining code blocks; grade the last boxed content containing an operator; accept an
unboxed "answer ... (X)" statement for choice tasks (case-sensitive letter). Caesar grading was correct (wrong examples
are real errors, e.g. "awlv" for "zvlu"). Re-grading the stored responses (job 11168204) gives the corrected base rates.
Implication: a format artefact in the grader would have been learned away in RL and read as fast "skill" learning.
